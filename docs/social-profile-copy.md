## Shared talking points (all platforms)

Use these when writing captions so the story stays consistent:

| Topic | Line to use |
| :--- | :--- |
| Who it’s for | University students who want somewhere calm and comfortable while they study |
| Feel | A place that feels like home |
| Location | Obuasi, Ghana |
| Spaces | Private and shared rooms; kitchen, study room, lounge, laundry |
| Wi-Fi | Wi-Fi throughout the building |
| How to start | Browse rooms online, then apply when you’re ready |
| Payment | MoMo or bank transfer; manager confirms your receipt |

**Avoid on social bios**

- Exact bed prices that change often (put those on the website)  
- Staff-only or system wording (“hold a bed”, “inventory”, “portal”)  
- Login emails, demo passwords, or admin instructions
